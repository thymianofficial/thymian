A hook is a TypeScript function you own, anchored to the Transaction — or the set
of Transactions — it applies to.

## Where hooks live

```bash
mkdir -p .thymian/sampler/hooks
```

Any file under `hooks/` is scanned, at any depth, named anything you like:

<FileTree>

- .thymian/sampler/hooks/
  - auth.ts
  - launches/
    - seed.ts
    - assertions.ts

</FileTree>

The layout carries no meaning — it is for your benefit. What decides where a
hook applies is its **target**, in the code.

<Aside type="tip" title="No setup needed">
  `@thymian/hooks` resolves through the sampler plugin itself, so a hook file
  runs with nothing generated and nothing installed beside it. Run [`thymian
  sampler init`](/references/plugins/sampler/hooks-api/#thymian-sampler-init)
  when you want your editor to complete Selectors and the compiler to check
  them.
</Aside>

## The six hook kinds

| Kind           | Runs                                    | Use it for                                  |
| -------------- | --------------------------------------- | ------------------------------------------- |
| `defineSample` | when the request is generated           | bodies, fixture files, the `authorize` flag |
| `beforeEach`   | before each request                     | headers, path parameters, seeding           |
| `afterEach`    | after each response                     | assertions, observations                    |
| `authorize`    | before a request that wants credentials | credentials, and nothing else               |
| `beforeAll`    | once, before the first request          | run-wide setup                              |
| `afterAll`     | once, when the run closes               | run-wide teardown                           |

Every hook **returns nothing and mutates in place**, and every registration is an
export:

```typescript
import { beforeEach } from '@thymian/hooks';

export const addTraceId = beforeEach(
  'GET /launches -> 200 (application/json)',
  (request) => {
    request.headers['x-trace-id'] = 'abc';
  },
);
```

<Aside type="caution" title="Export it">
  A registration you build but never export does nothing. Discovery is
  export-based, so `beforeEach(sel, fn);` on its own line is silently inert.
</Aside>

## Choosing a target

### One Transaction

Pass its Selector. This is the tightest and the most precisely typed option —
inside the callback, the request and response types are that Transaction's.

```typescript
export const shape = beforeEach(
  'POST /launches (application/json) -> 201 (application/json)',
  (request) => {
    request.body = { missionName: 'Artemis II' };
  },
);
```

### A few Transactions

Pass a list of Selectors.

```typescript
export const shared = beforeEach(
  [
    'GET /launches -> 200 (application/json)',
    'GET /astronauts -> 200 (application/json)',
  ],
  (request) => {
    request.headers['x-shared'] = 'yes';
  },
);
```

### A set of Transactions

Pass a filter. Fields AND-combine, a list within a field OR-combines, and `not`
excludes.

```typescript
export const negativeCases = afterEach(
  { statusClass: '4XX', not: { status: 401 } },
  (response, ctx, utils) => {
    utils.info(`negative case responded ${response.statusCode}`);
  },
);
```

### A whole subtree

Use a path glob. `*` is exactly one segment; a trailing `**` is one or more.

```typescript
export const admin = beforeEach({ path: '/admin/**' }, (request) => {
  request.headers['x-admin'] = 'yes';
});
```

`/admin/**` covers everything _under_ `/admin`, including paths added to your API
description later — but not `/admin` itself.

See the [filter reference](/references/plugins/sampler/hooks-api/#filters) for
every field and the full glob grammar.

## Finding a Selector

```bash
npx thymian sampler show 'GET /launches -> 200 (application/json)'
```

It prints the request that Transaction would send. Get the Selector slightly
wrong and it prints the nearest matches, which is the fastest way to find the
exact spelling.

## Composing several hooks

Several hooks of the same kind on one Transaction all run, in registration order:
file order on the outside, and source order within each file. `defineSample` is
the exception — at most one per Transaction, and a second is reported as a
conflict when the hooks load.

## When a hook stops matching

A Selector that names nothing, a glob that matches nothing, and a filter whose
values intersect nothing all **fail the run**, naming the hook file and the
export:

```
1 sampler hook does not resolve against the loaded API description.
Try this:
  * seed.ts (export "seedAstronaut"): beforeEach targets the selector
    "GET /astronauts/{id} -> 200 (application/json)", which names no transaction
    in the loaded API description
  * Did you mean one of these selectors?
  * "GET /astronauts/{astronautId} -> 200 (application/json)"
```

A hook is never quietly re-bound to a nearby Transaction. That is the point of
anchoring to a fully-qualified Selector.
