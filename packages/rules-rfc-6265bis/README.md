## @thymian/rules-rfc-6265bis

A rule set for HTTP cookies as defined in "Cookies: HTTP State Management Mechanism", the Internet-Draft that will obsolete RFC 6265 (draft-ietf-httpbis-rfc6265bis-22, December 2025): the `Set-Cookie` header a server sends, the `Cookie` header it receives, and the cookies a browser ignores or caps although the server sent them.

Two kinds of statement are in scope: the draft's own requirements on servers, wherever they stand, and every step of the browser's algorithms in §5.5–§5.7 at which a browser ignores a cookie or one of its attributes, or shortens its lifetime. Such a step binds the browser, but what triggers it is in the server's own response. The Coverage section below is generated from the package's coverage record and states how many of those units the shipped rules check.

The source is still an Internet-Draft, so the package and its rule ids carry the slug `rfc-6265bis`. When the RFC is published, they are renamed to the RFC's number in a release that announces it as a breaking change.

## Installation

```bash
npm install @thymian/rules-rfc-6265bis
```

Then add it to the `ruleSets` of your `thymian.config.yaml`:

```yaml
ruleSets:
  - '@thymian/rules-rfc-6265bis'
```

> **Getting started with Thymian?** See the [main Thymian package](https://www.npmjs.com/package/thymian) for quick installation and first-run instructions.
